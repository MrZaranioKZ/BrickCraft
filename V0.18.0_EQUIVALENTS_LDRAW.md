# BrickCraft V0.18.0 — Remplacer une référence manquante par un équivalent LDraw

## Dans le jeu

1. **Studio → Importer → Projet → Analyser / charger** un `.io`, `.mpd`, `.ldr` ou `.bcpx`.
2. Cliquer sur **Pièces manquantes / chercher**.
3. À côté d'une référence absente, cliquer sur **Équivalents**.
4. Consulter les suggestions de la bibliothèque LDraw installée, dont les noms affichés proviennent du catalogue réel.
5. Cliquer sur **Choisir** pour une suggestion, ou taper une référence installée dans **Cible**.
6. Cliquer sur **Remplacer** et confirmer. Toutes les occurrences portant EXACTEMENT l'identifiant source sont modifiées en mémoire.
7. Dans l'importeur, aller dans **Actions → Sauver .bcpx** pour enregistrer une copie. Le `.io` d'origine n'est jamais modifié. Tu peux ensuite **Projeter dans le monde** le projet ainsi corrigé.

## Exemples de variantes

- `4079b` → `4079` (identifiant de base privilégié)
- `4497b` → `4497`
- `57029c01` → `57029ac01` (caractère supplémentaire)

Ces correspondances n'apparaissent que si la pièce cible existe dans la bibliothèque chargée ET possède une géométrie exploitable. L'algorithme inspecte les codes des pièces et affiche le nom fourni par LDraw. Il ne garantit aucune équivalence de dimensions ou de connecteurs, et ne remplace jamais les pièces automatiquement.

## Garanties

- Couleurs, coordonnées décimales et matrices 3 × 3 inchangées.
- Nombre de pièces inchangé.
- Aucune modification du fichier d'origine, des projections déjà posées dans le monde ou du catalogue LDraw.
- Rapport de diagnostic mis à jour après chaque remplacement et historique inclus dans le futur `.bcpx`.
- Annulation avant confirmation ; pour revenir sur un remplacement appliqué, recharger le fichier original (une confirmation protège les modifications non sauvegardées).
- Aucun téléchargement Internet obligatoire ni substitution vers une référence absente.

## Tests

- `TESTER_EQUIVALENTS_V018_WINDOWS.bat` : candidats, tests des trois exemples, historique, conservation des transformations, sauvegarde/relecture BCPX.
- `TESTER_GRANDS_SETS_V017_WINDOWS.bat` : tests précédents de capacité et pièces manquantes.
- `CONSTRUIRE_WINDOWS.bat` : compilation Fabric 1.21.1, JDK 21. Compiler dans un répertoire neuf et conserver une sauvegarde du monde.

**Limite :** le matching compare les références, pas les géométries elles-mêmes. Une référence voisine peut être une pièce mécaniquement différente : il faut contrôler l'aperçu et les connexions avant de projeter le modèle.
