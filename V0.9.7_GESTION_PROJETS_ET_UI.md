# BrickCraft V0.9.7 — Gestion des projets et correction de l'interface

## Pourquoi cette version ?
L'éditeur libre V0.9.6 affichait les widgets de l'écran d'importation sous les siens : les textes et contrôles se superposaient. Il manquait également un moyen simple de retirer une projection déjà installée dans un monde.

## Interface corrigée
- L'éditeur libre rend maintenant **uniquement la vue 3D** du parent. Aucun bouton ou libellé de l'importeur n'est rendu derrière l'éditeur.
- Caméra de l'éditeur : clic droit-glisser (orbite), clic milieu-glisser (déplacement), molette (zoom).
- Boutons de sauvegarde et de retour déplacés pour éviter le pied d'écran.
- Les modifications non sauvegardées sont signalées : confirmation avant déchargement, remplacement du fichier importé ou retour au Studio.

## Décharger / retirer : ce sont deux actions différentes

### 1. `Décharger le projet (éditeur)`
Dans **B → Studio → Importer .io/LDraw** : libère le projet actuellement chargé en RAM, son aperçu et ses caches. Il n'efface **aucun fichier**, **aucune projection du monde**, ni les LEGO déjà posés. Un fichier reste sélectionné afin de pouvoir le recharger avec `Analyser`.

### 2. `Projections du monde / retirer`
Dans le même menu : ouvre la liste des projections précisées présentes à moins de **192 blocs** du joueur, dans les **chunks déjà chargés** de la dimension en cours. Les ancres sont identifiées par coordonnées et nombre de pièces. Choisis une projection, clique `Retirer la projection sélectionnée`, puis confirme.

Le serveur impose le **mode Créatif**, la distance maximale, les permissions de modification et la présence exacte d'un bloc `brickcraft:precise_display` à l'ancre demandée. Une seule ancre est retirée, pas les constructions normales ni les fichiers `.io` ou `.bcpx`. Les VBO associés sont libérés à la réception de la confirmation serveur.

**Limites** : ne liste pas les projections situées dans des chunks non chargés, hors de portée ou dans une autre dimension. Les constructions du Studio classique faites de blocs BrickCraft ne sont pas concernées : il existe déjà le bouton `Vider atelier` pour le projet Studio, qui n'efface pas les blocs du monde.

## Installation
1. Fais une copie du monde et du projet source avant de remplacer le JAR.
2. Pour une mise à jour, extrais le PATCH dans les sources V0.9.6 ; sinon utilise le ZIP complet.
3. Facultatif : `TESTER_GESTION_PROJETS_WINDOWS.bat` puis `TESTER_PLACEMENT_LIBRE_WINDOWS.bat`.
4. Exécute `CONSTRUIRE_WINDOWS.bat`, installe le JAR dans `mods` et retire la version précédente.
