# BrickCraft V0.9.6 - Atelier de placement libre LDraw

## Nouveau dans cette livraison

- Dans Minecraft, touche **B**, puis ouvre **Importer .io / LDraw** dans le Studio, et clique sur **EDITEUR LIBRE 0.9.6**.
- Tu peux aussi ouvrir l'editeur sans avoir analyse un projet : il cree un atelier vide.
- L'editeur utilise la **previsualisation 3D existante** du panneau Import, recomposee apres chaque modification.
- Choisis les pieces par index (les projets `.io` peuvent contenir des milliers de pieces). Modifie ID LDraw, code couleur, X/Y/Z **en unites LDraw (LDU)**, puis **Appliquer champs**.
- Boutons de deplacement X/Y/Z ±, rotation RX/RY/RZ ±, remise a zero, Ajouter, Dupliquer et Supprimer.
- Pas de translation 20 / 8 / 4 / 1 / 0,25 LDU **ou saisis ton pas personnalise** dans le champ. **20 LDU = un tenon / 1 bloc MC**, 8 LDU = une plaque LEGO; **Y LDraw est positif vers le bas**, a l'inverse de Minecraft.
- Pas de rotation 90 / 45 / 15 / 5 / 1 / 0,25 degre **ou une valeur personnalisee**, sur les trois axes **locaux du projet**.
- Les rotations composees se font en multipliant des matrices 3x3 : le programme **ne decompose pas** les rotations arbitraires deja presentes dans les imports `.io`.
- Annuler/retablir (64 actions max), avec Ctrl+Z / Ctrl+Y, Ctrl+D pour dupliquer, Ctrl+S pour enregistrer.
- **Enregistrer un nouveau .bcpx** cree une nouvelle sauvegarde dans `config/brickcraft/imports/`, sans modifier le fichier original (suffixe `_free_v096`).
- Bouton **Retour a l'apercu / projection** pour inspecter le resultat et le projeter via le flux existant de la V0.9.5.2.

## Limites transparentes

- La V0.9.6 ajoute **l'edition precise de projets dans l'interface Minecraft**, mais pas encore de placement libre par clic direct dans le monde. Ce prochain palier necessitera une selection 3D des pieces, un controle cote serveur, et des collisions LEGO fractionnaires.
- Le bouton `Importer dans le Studio (strict)` reste l'ancien convertisseur cubique, qui arrondit les transformations. Pour conserver les rotations, utilise **Projeter dans le monde (BETA)** apres retour a l'apercu.
- L'atelier libre V0.9.6 est limite a 4 096 pieces, comme la projection actuelle. Les modeles plus gros se visualisent encore via l'import, mais ne sont pas editables dans ce module.
- Un ajout doit correspondre a une **reference geometrique connue** de la bibliotheque LDraw installee (`config/brickcraft/complete.zip` et supplements eventuels).
- La camera d'apercu existante centre **toute la construction**. La selection par piece ne dispose pas encore d'un surlignage individuel.
- Le moteur de VBO de la V0.9.5.2 n'a pas ete modifie.

## Installation

1. Conserve une copie de ton monde et de ta version precedente.
2. Applique le ZIP patch depuis la racine du projet V0.9.5.2, ou extrais les sources completes.
3. Lance `TESTER_PLACEMENT_LIBRE_WINDOWS.bat` et `CONSTRUIRE_WINDOWS.bat`.
4. Installe le JAR compile dans `mods`, sans conserver d'autre version de BrickCraft en meme temps.

## Tests

`TESTER_PLACEMENT_LIBRE_WINDOWS.bat` lance un test Java independant du serveur couvrant les matrices XYZ, les rotations non orthogonales, les mouvements sub-LDU, la duplication, la suppression, l'annulation/retablissement et la sauvegarde BCPX.
La compilation complete Fabric et l'affichage en jeu ne peuvent pas etre garantis sans un build reel avec Yarn/Fabric et essai Minecraft.
