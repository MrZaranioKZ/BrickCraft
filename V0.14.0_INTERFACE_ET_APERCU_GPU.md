# BrickCraft 0.14.0 - Refonte de l'interface et apercu GPU

## Zones de travail

- **Importeur** : l'ancien empilement de boutons est remplace par les onglets **Projet / Visuel / Actions** ; actions indisponibles grisees, retour au Studio fixe, barre d'etat separee, dimensions de panneaux adaptatives, informations limitees a leur zone pour eviter les chevauchements.
- **Projet** : navigation dans les fichiers, analyse et actualisation.
- **Visuel** : trois modes explicites (Points / Volumes / Maillage), bascule GPU/CPU avec O et recentrage de la camera.
- **Actions** : editeur libre, conversion stricte vers le Studio, BCPX sans perte, projection Minecraft, gestion des projections et dechargement. Les actions existantes n'ont pas ete supprimees.
- **Studio classique** : catalogue elargi, onglets clarifies, bouton importer/sauver dans l'en-tete des ecrans assez larges, panneaux d'options pour les ecrans etroits, onglets et outil actifs soulignes.

## GPU / performance

- Le VBO 2D dessine en coordonnees GUI utilise maintenant une matrice orthographique explicite adaptee aux dimensions *scaled* de la fenetre ; il ne depend plus de la matrice 3D pouvant rester active quand le screen est dessine.
- Le mode **Volumes** utilise lui aussi le VBO GPU mis en cache et ne re-rasterise plus toutes les faces CPU a chaque frame.
- Le mode **Maillage** conserve le chargement progressif des geometries et le LOD adaptatif existant.
- La reconstruction VBO est reservee aux changements de camera / donnees / taille du viewport / mode.
- En mode CPU de secours, le nombre de volumes effectivement dessines est borne a 700, avec indication d'echantillonnage. Aucune piece n'est omise dans le rendu GPU.
- En cas d'exception GPU, retour au CPU avec message diagnostique et reactivation possible par O.

## Installation

1. Fais une sauvegarde de ton monde avant tout changement de JAR.
2. Lance `TESTER_UI_GPU_V014_WINDOWS.bat` pour les tests Java purs, puis `CONSTRUIRE_WINDOWS.bat` pour compiler (Java 21 + Gradle/Fabric).
3. Remplace uniquement l'ancien JAR dans le dossier `mods`. Ne garde pas deux versions de BrickCraft.
4. Lance Minecraft 1.21.1, ouvre l'importeur et charge ton projet du chateau.
5. Dans **Visuel** choisis **Maillage** et verifie si le modele entier s'affiche ; teste ensuite **Volumes** et controle le FPS et la rotation.
6. Appuie sur O pour comparer le mode CPU de secours, puis repasse en GPU.

## Limites et prudence

- La compilation Fabric complete et un essai reel en jeu ne sont pas realises dans cet environnement ; la correction GPU reste a confirmer visuellement sur ton installation.
- L'apercu GPU du Studio/importeur est un **rendu 2D de triangles 3D deja projetes sur CPU**, pas un moteur 3D complet avec z-buffer. Une toute petite partie des faces peut etre occluse incorrectement sur des grands modeles.
- La carte du monde, le reseau, les donnees BCPX et le moteur des collisions V0.13 ne sont pas modifies.
- Le rendu CPU de secours reduit la densite des volumes pour eviter le blocage sur les projets de plusieurs milliers de pieces.
