# BrickCraft V0.25.1 RC2 — Formatage des langues, interface et ergonomie

Base : V0.25.0 RC1. Minecraft 1.21.1 / Fabric Loom 1.7.4.

## Bugs confirmés et corrigés

- **« Format error: SHAPES » / « Format error: Height: AUTO » / pages et finitions** : cause commune dans `BrickI18n.fmt`. L'ancienne méthode `I18n.translate(key)` tentait de formater `%s` sans arguments. On lit désormais le modèle brut avec `Language.getInstance().get(key)` avant de fournir les arguments. Les paramètres `%s` et `%%` sont testés.
- **Studio :** indicateurs POSER / DÉPLACER / EFFACER désormais localisés dans la ligne des compteurs, avec phrase complète FR/EN.
- **Studio :** états des guides d'accroche, réinitialisation de rotation et cadrage de caméra reformulés proprement.
- **Importeur :** résumé court (nombre de pièces, formes, références manquantes), chemin relatif lisible pour le dossier BrickCraft, diagnostic GPU plus discret.
- **Éditeur libre :** diagnostic GPU masqué dans la vue intégrée (il reste dans l'importeur). Actions Ajouter, Dupliquer, Supprimer, Appliquer, Annuler, Rétablir et Réinitialiser : messages FR/EN complets, sans « Part ajoutée » en anglais.
- **Éditeur libre :** réservations verticales pour garantir un espace entre la dernière rangée d'actions et le pied de page Sauvegarder. La nomenclature des fichiers devient `_free.bcpx` au lieu de `_free_v099.bcpx`, sans renommer les sauvegardes existantes.
- **Pièces manquantes :** avec zéro référence, les boutons inactifs / non pertinents sont masqués. Les compteurs utilisent une traduction paramétrée. Les messages « rapport enregistré » et « bibliothèque rechargée » sont plus courts.

## Vérifications automatisées

- 11 groupes de tests autonomes : réussis (moteurs LEGO, collisions, formats, Studio, commandes, ressources).
- Analyse syntaxique Java 21 : 107 fichiers passés avec le compilateur officiel, en mode analyse seule (sans résoudre les dépendances Fabric).
- 11 fichiers de langue avec mêmes clés / formats de paramètres : vérifiés.
- Test Java du bug de formatage avec simulation de l'ancien comportement : réussi.
- Test d'espacement des boutons pour des hauteurs GUI entre 280 et 1000 : réussi.
- Contrôle statique des ressources : aucune erreur bloquante.

## Limites / avant V1.0

- Aucune compilation Fabric complète ni essai visuel réel dans Minecraft sur cette machine.
- Les neuf langues secondaires ont encore des phrases en repli anglais. FR/EN restent les langues prioritaires.
- Certaines phrases historiques du mod sont encore construites par fragments et méritent une migration ultérieure vers des clés paramétrées.
- Les modifications de disposition sont conservatrices. Tester notamment l'éditeur libre avec l'échelle GUI habituelle et en petit écran.

## Procédure

1. Sauvegarder les mondes et le JAR actuel.
2. Extraire dans un nouveau dossier ; exécuter `TESTER_CORRECTIFS_V0251_WINDOWS.bat`.
3. Compiler avec `CONSTRUIRE_WINDOWS.bat`.
4. Tester sur une copie du monde en français puis anglais. Vérifier Studio (Formes, Couleurs, Réglages), éditeur libre et écran Pièces manquantes.
