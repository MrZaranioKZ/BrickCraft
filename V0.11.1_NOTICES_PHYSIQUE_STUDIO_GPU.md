# Notes techniques V0.11.1

## Notice
`BrickGuideController.nextTargets()` expose les volumes OBB de la prochaine étape; `BrickGuideTargetOverlay` les dessine dans `AFTER_ENTITIES` (48 cadres max) à partir des matrices originales. Le filtre GPU existant conserve l'affichage progressif des étapes.

`Vérifier pièces` cherche des BrickCellEntity à proximité, compare référence et code couleur. **Ceci n'est pas une validation géométrique** : rotation, connecteurs et position exacte ne sont pas vérifiés. `Confirmer (manuel)` reste explicitement manuel.

## Physique
`PreciseCollisionPlan` convertit les AABB orientées des pièces en cellules voxel complètes. L'activation ne remplace jamais les blocs non-Air; vérifie permissions/chunks/hauteurs avant toute création. Les cellules sont écrites dans le NBT de l'ancre avant d'être posées à hauteur de 128 blocs par tick; édition du modèle refusée tant que les collisions sont actives. C'est une approximation pleine : elle bouche certaines cavités LEGO. Le nettoyage de blocs hors chunks chargés lors d'une suppression manuelle n'est pas garanti; utiliser Physique OFF quand tous les chunks sont chargés avant de retirer l'ancre.

## Studio GPU
`StudioPreviewGpu` convertit les faces 2D projetées en TRIANGLES POSITION_COLOR puis les charge dans un VertexBuffer. Il les redessine sans nouvelle projection CPU tant que la caméra, le modèle et la taille de l'écran ne changent pas. Les formes LDraw sont préparées graduellement. `O` sert de repli CPU. La validation des matrices GUI nécessite Minecraft réel.

## Tests
Le script Windows teste le planificateur physique et le parseur des notices. La compilation Fabric complète et les essais client/serveur sont nécessaires avant d'adopter la version pour un vrai monde.
