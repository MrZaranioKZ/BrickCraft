# BrickCraft V0.19.0 — Supprimer les pièces manquantes

## Nouveautés

Écran **Studio > Importer > Projet > Pièces manquantes** :

- **Suppr.** à côté de chaque ID : retire **toutes les occurrences** de cette seule référence après confirmation.
- **Supprimer tout** : retire d'un coup **uniquement les références encore classées comme manquantes** dans l'analyse courante. Les pièces installées restent présentes.
- Confirmation obligatoire pour les deux actions, avec le nombre d'occurrences concernées.
- Les suppressions mettent immédiatement à jour l'aperçu 3D, le cache GPU, les totaux et le rapport de références manquantes.
- Historique textuel des suppressions conservé dans le projet précis.
- Le fichier source `.io`, `.ldr` ou `.mpd` n'est pas modifié. Pour enregistrer le projet nettoyé, choisir **Retour import > Actions > Sauver .bcpx**. La copie porte un suffixe `_corrige_v019.bcpx`.
- Pour annuler une suppression non sauvegardée, recharger le fichier d'origine depuis l'onglet Projet (confirmation si des modifications sont en cours).
- Un projet vidé entièrement reste sauvegardable ; sa projection dans le monde est refusée avec un message clair.

Attention : supprimer une pièce manquante modifie la composition du modèle : cela peut créer des trous ou enlever des détails. Les notices automatiques (par couches/pièces) correspondent à la projection nettoyée ; le guide original `0 STEP` d'un `.io` peut ne plus correspondre après suppression de références et ne sera pas faussement associé.

## Test Java indépendant

`TESTER_SUPPRESSION_MANQUANTES_V019_WINDOWS.bat` vérifie :

1. Suppression d'un ID en plusieurs occurrences, indépendamment des majuscules et du suffixe `.dat`.
2. Suppression groupée sans toucher aux références conservées.
3. Préservation exacte des coordonnées, couleurs, matrices et du fichier source.
4. Traçabilité des changements dans la copie BCPX.
5. Sauvegarde/relecture d'un projet entièrement vide.

Le script accepte également des chemins de fichiers `.io` en paramètres pour les analyser.

## Installation

1. Décompresser le ZIP dans un nouveau dossier.
2. Exécuter `TESTER_SUPPRESSION_MANQUANTES_V019_WINDOWS.bat`.
3. Exécuter `CONSTRUIRE_WINDOWS.bat` (nécessite les dépendances Gradle/Fabric sur la machine).
4. Remplacer l'ancien JAR BrickCraft par le nouveau dans `mods` (ne pas laisser deux versions).

**Limite de validation :** tests Java indépendants réalisés ; la compilation complète et l'interface Fabric 1.21.1 doivent être validées sur le PC cible.
