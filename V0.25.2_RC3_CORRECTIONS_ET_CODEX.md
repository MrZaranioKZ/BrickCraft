# BrickCraft 0.25.2 RC3 — Corrections de localisation, interface et transfert Codex

**Base :** 0.25.1 RC2. **Cible :** Fabric 1.21.1 / Java 21. **Statut :** RC, pas V1.0 certifiée.

## Correctifs sur les captures du 9 novembre

- Studio : restauration de session, choix/recoloration, changement de plateau, messages de rotation, sauvegarde, chargement et progression transmis via des **phrases complètes** avec variables plutôt que par fragments de traduction.
- Import : progression du calcul GPU et affichage des origines LDraw localisés ; messages de dossiers reformulés. Les statistiques GPU restent visibles dans l'aperçu complet (utiles pour le diagnostic).
- Pièces manquantes : description de secours localisée, rapport d'installation de `.dat`, historique de remplacement/suppression, confirmations et légendes.
- Équivalences LDraw : message « cible », vérifications d'ID, avertissement de variantes proches, quantité de suggestions, confirmation de remplacement, retour.
- Projections : compteurs, ligne de sélection, confirmations de collision/suppression entièrement traduits, avec information de l'ancre et du fichier conservé.
- Dialogues : les textes d'avertissement sont **découpés en lignes** selon la largeur disponible, plutôt que tronqués à une seule ligne.
- Physique : messages serveur en `Text.translatable(...)`, traduits chez le joueur ; progression envoyée dans la barre d'action au lieu d'inonder le chat. Les événements de fin restent dans le chat.
- « 1 parts » : reformulation des compteurs dans l'importeur et la liste des projections en `Parts: 1`, pour éviter l'accord incorrect.
- Nom de version de la source : `mod_version=0.25.2-rc3`.

## Vérifications

`TESTER_CORRECTIFS_V0252_WINDOWS.bat` lance : analyse syntaxique Java, vérification des anciennes erreurs de formatage, tests ciblés, audit des 11 langues, 11 groupes de régression. Pour produire le diagnostic des textes, lancer aussi :

```text
python tools/AUDIT_I18N_LAYOUT_V0252.py
```

Ce script crée `AUDIT_I18N_RESTANT_V0252.csv` avec **fichier, ligne, catégorie et extrait**, ainsi que `.json` pour le bilan de couverture. Les candidats ne sont pas tous des bugs confirmés.

## Ce qui n'est pas encore fini

1. Les neuf langues au-delà du français et de l'anglais comportent **plusieurs centaines de textes identiques à l'anglais**. Une simple présence de clés JSON ne signifie pas une traduction réelle.
2. Il reste des chaînes Java assemblées dynamiquement et des `Text.literal(...)` dans d'autres écrans et services (rapport CSV).
3. Aucune compilation Fabric complète ni essai graphique sur Minecraft avec l'échelle GUI de l'utilisateur n'est certifié ici. Le script n'effectue que des tests autonomes et statiques.
4. PBR via Iris, rotation WorldEdit/Axiom, rendu de gros projets et sécurité des données doivent être vérifiés en jeu avant publication V1.0.

**Installation :** sauvegarder d'abord les mondes et le dossier `config/brickcraft/`, extraire la source dans un dossier neuf, exécuter `TESTER_CORRECTIFS_V0252_WINDOWS.bat`, puis `CONSTRUIRE_WINDOWS.bat`. Remplacer le JAR précédent uniquement après compilation et essais.
