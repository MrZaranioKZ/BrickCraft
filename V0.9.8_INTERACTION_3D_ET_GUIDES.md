# BrickCraft V0.9.8 — interaction LEGO, prochain chantier guides

## Version V0.9.8 — éditeur libre

- Clic gauche sur les volumes **orientés** des pièces de l'aperçu LDraw : sélection ; `Maj + clic` parcourt les volumes superposés.
- Surbrillance filaire jaune sur la pièce sélectionnée ; axes X (rouge), Y (vert), Z (bleu). Les poignées gardent une taille visible, même pour une grosse construction.
- Bouton **Mode: bouger / Mode: tourner** ; touches `G` et `R` hors champ texte.
- Glisser une poignée pour déplacer / tourner selon l'axe. Le pas est donné par **Pas pos. / Pas rot.** ; les champs restent éditables manuellement.
- Clic droit glissé = orbite ; clic milieu glissé = panorama ; molette = zoom.
- Ctrl+Z / Ctrl+Y / Ctrl+D / Ctrl+S = annuler / rétablir / dupliquer / sauvegarder. Chaque glissement crée une seule entrée dans l'historique.
- Sauvegarde non destructive en `.bcpx`, position LDU fractionnaire et matrice 3×3 conservées.
- Interface repliée verticalement lorsque la hauteur GUI est réduite ; autres commandes au clavier sur les petits écrans.

### Limites de cette version

- Le clic dans l'aperçu utilise **le volume orienté de la pièce**, pas un lancer de rayon sur chaque triangle. C'est une sélection assistée avec `Maj+clic`, pas une sélection parfaite des faces creuses.
- Les poignées sont dessinées en surimpression de l'aperçu **2D projeté** ; il ne s'agit pas encore d'un gizmo 3D Minecraft ou d'un placement en direct dans le monde.
- L'atelier n'altère pas une projection déjà posée dans le monde tant qu'un export n'est pas effectué. Le rendu GPU et les fichiers existants ne sont pas modifiés.
- Les changements répétés dans une construction de plusieurs milliers de pièces peuvent provoquer des ralentissements momentanés de l'aperçu logiciel ; le rendu du monde, lui, reste inchangé.
- Limite actuelle de l'éditeur libre : `PreciseWorldModel.MAX_PARTS` (4096 pièces).

## Futur module Construction Guide — layer by layer / step by step

**Deux modes indépendants** :

1. **Couches (« layer by layer »)** : isolation d'une couche ou tranche de hauteur, ascension couche par couche, affichage fantôme des autres pièces. Pour les pièces inclinées, calculer les **bornes géométriques réelles**, plutôt que seulement l'origine LDraw.
2. **Étapes (« step by step »)** : progression par étape native du `.io`/MPD si présente (`0 STEP`, sous-modèles et transformations), sinon séquence **suggérée** et modifiable. Une étape peut contenir plusieurs pièces, avec surbrillance des pièces ajoutées.

Les formats actuels `.bcpx` v1 contiennent **une liste aplatie** de pièces et leurs matrices, mais ne préservent pas les sections `0 STEP`, les sous-assemblages ni les identifiants stables. Il faut donc ajouter des métadonnées de guide (par exemple en `.bcguide` séparé, et à terme `.bcpx` v2) :

- `partUid` persistant par occurrence, indépendamment de l'index de tableau ;
- `submodelUid` et liens de parenté ;
- `stepId`, ordre, titres/narration éventuels ;
- niveau ou intervalle de hauteur ;
- matrice LDraw d'origine, jamais arrondie ;
- visibilité par lot GPU et surbrillance pour conserver les FPS.

Le projet inclut un **prototype Java isolé `BrickGuidePlanner`**, qui groupe les *origines* en tranches de 8 LDU ou la liste aplatie en lots de 20 pièces. C'est une base de tests, **pas une vraie notice d'assemblage**, et **aucun bouton de couches/étapes n'est ajouté à l'interface V0.9.8**.

## Installation

1. Faire une copie du monde et de la V0.9.7.
2. Mettre les sources complètes dans un nouveau dossier, ou appliquer le patch à la racine de la V0.9.7.
3. Lancer `TESTER_INTERACTION_098_WINDOWS.bat` ; il faut Java 21 et la bibliothèque LDraw `config/brickcraft/complete.zip` pour tous les tests.
4. Lancer `CONSTRUIRE_WINDOWS.bat` pour compiler Fabric 1.21.1 (Internet éventuellement nécessaire au premier lancement de Gradle).
5. Installer le JAR généré, en retirant l'ancien du dossier `mods`. Conserver le château de test pour comparaison.

**Statut de validation** : tests Java des outils (avec la bibliothèque locale), compilation simulée de l'écran ; compilation Fabric complète et essai dans le jeu non exécutés ici.
