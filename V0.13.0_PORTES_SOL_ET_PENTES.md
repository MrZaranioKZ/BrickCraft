# BrickCraft V0.13.0 — Collision du sol, ouvertures et pentes LEGO

Compatibilité cible : **Minecraft Java 1.21.1 / Fabric / Java 21**.

## Correctifs

1. **Sol et ancre** : V0.12 sautait toutes les collisions de la cellule 1×1×1 de l'ancre de projection. La collision de cette zone est maintenant enregistrée dans l'entité d'ancrage et récupérée depuis le NBT/synchronisée avec le client. Le bloc d'ancrage dispose d'une collision variable, indépendante du petit contour de sélection visible.
2. **Pieds légèrement en l'air** : le rasteriseur pouvait créer une tranche solide supplémentaire de 1/8 de bloc au-dessus d'une face exactement alignée sur une limite. Les voxels extérieurs à un volume fermé sont filtrés en préservant les maillages fins/ouverts.
3. **Portes, arcs et ouvertures** : le remplissage flood-fill par pièce est remplacé par un test d'intérieur sur trois directions perpendiculaires, afin d'éviter qu'une fermeture accidentelle de quelques microvoxels ne remplisse une grande cavité. Une ouverture large reste traversable si la hitbox du joueur y tient. La résolution de collision reste **1/8 de bloc** ; une ouverture plus étroite ne peut pas être garantie.
4. **Pentes automatiques** : lorsqu'un joueur se trouve à proximité de véritables cellules de collision BrickCraft, l'attribut vanilla `minecraft:generic.step_height` est ajusté de manière temporaire selon sa taille (de 0,25 à 0,90 bloc). Il revient à sa valeur normale dès que le joueur s'éloigne. Le réglage d'échelle/hitbox U de V0.12 est conservé.
5. **Données incomplètes** : une ancienne cellule physique sans masque 8×8×8 ne bloque plus un bloc Minecraft entier par défaut. Elle doit être reconstruite.

## Installation depuis V0.12.0

1. **Sauvegarder le monde.** Conserver l'ancien JAR.
2. Dans l'ancienne version, sélectionner la projection et faire **Physique OFF** ; attendre dans le chat que toutes les cellules soient supprimées avant de fermer le jeu.
3. Remplacer le mod par le JAR V0.13.0 compilé à partir de ce ZIP ; ne pas installer plusieurs versions simultanément.
4. Lancer `TESTER_PHYSIQUE_V013_WINDOWS.bat` pour les tests algorithmiques sans Minecraft. Puis `CONSTRUIRE_WINDOWS.bat` pour produire le JAR Fabric.
5. Dans une **copie** du monde, sélectionner la projection et faire **Physique ON** ; attendre le message `activee` et rester dans les chunks concernés.
6. Tester au sol, sous une porte, dans une arche creuse, sur une pente, à taille ×1 puis ×0,125/×0,25. Utiliser le mode **survie sur le monde de test ou créativité sans voler** pour le test de marche.

**Important :** l'ancien masque V0.12 doit être recalculé ; ne pas supposer que le remplacement du JAR suffit.

## Limites connues et sécurité

- Les collisions du maillage restent quantifiées à 1/8 de bloc. Le logiciel ne calcule pas encore des collisions triangle-précises ni des rampes lisses continues ; le franchissement est une succession automatique de petites marches.
- Si la projection chevauche des blocs Minecraft non-air (terrain, murs, constructions), **ces blocs ne sont pas remplacés ni évidés**. Minecraft reste solide à ces endroits : il faut projeter le modèle dans un volume libre pour explorer les intérieurs. Le nombre de cellules ignorées à cause du terrain est annoncé dans le chat lors de l'activation.
- Si un trou est plus étroit que le joueur (largeur hitbox = environ 0,6 × taille), la réduction du joueur est nécessaire.
- Les pièces LDraw très complexes ou mal fermées peuvent encore créer des défauts. Le nouveau test de parité augmente le coût de préparation du maillage ; la construction du plan reste synchrone et les plafonds de 2 millions de triangles / 16 000 cellules sont conservés. Grand château : attente et TPS réduits possibles.
- Chunks déchargés : conserver tous les chunks concernés chargés pendant ON/OFF ; ne pas casser l'ancre pendant l'opération. Utiliser une copie de monde.
- Tests **Java purs** des cubes pleins, tubes, pente, rotation, porte, surface ouverte, ancre et correction de flottement : réussis. La compilation Fabric complète, la validation en jeu et les performances du château n'ont pas été réalisées dans cet environnement.
